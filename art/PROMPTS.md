# Home page film: image prompts

The opening of the home page is a short scroll-driven film, "A drop of blood on
the ice": Hansall and the young Hannah Icetear face each other on a frozen
field, a spirit passes between them, a single drop of blood falls, the ice
cracks and the title appears. These are the ChatGPT prompts for its images.

## How to use them

- Make every image in one single ChatGPT chat, in the order below, starting
  with 01. Later prompts point back to the battlefield image in that chat.
- Paste the style line at the start of every prompt.
- Attach a reference picture only where the table says so. Attach the right
  character every time, and never both at once, so ChatGPT does not mix them.

| Image | Attach |
|---|---|
| 01-field, 01-field-portrait, 02-foreground | nothing |
| 03-hansall-stand, 04-hansall-turn, 05-hansall-attack | Hansall's picture |
| 06-hannah-stand, 07-hannah-turn, 08-hannah-attack | Hannah's picture |
| 09-spirit, 10-ice, 10-ice-portrait | nothing |
- Transparent images: if one comes back on a solid background, keep it anyway.
  The background can be cut out afterwards.
- Save each image with the file name given, into
  `C:\Users\lashl\Downloads\Icetear film\images\`.

## Style line

> Dark fantasy painting, cinematic and painterly, highly detailed illustrated
> fantasy style. Moonlit winter night. Palette: deep night blue #0b1320, frost
> blue-white #cfe3f2, steel grey #5d6b78, royal blue #1d3a6e and silver; the
> only warm colours are antique gold #c9a45c, rust red #8b2e1f and blood red
> #6e0f14. Cold moonlight from the upper left, soft volumetric mist, fine film
> grain, 35mm lens, calm and ominous. Never include text, letters, logos,
> watermarks, signatures or borders, and nothing modern.
